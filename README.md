# دوتسک | DevTasks

یک برنامه ساده و راست‌چین برای مدیریت وظایف روزانه با رابط کاربری فارسی.

## امکانات
- افزودن، ویرایش و حذف وظایف
- علامت‌گذاری وظایف انجام‌شده
- دسته‌بندی وظایف
- جست‌وجو و فیلتر
- نمایش آمار وظایف
- ذخیره خودکار اطلاعات در مرورگر با `localStorage`
- طراحی واکنش‌گرا برای موبایل و دسکتاپ

## اجرا
فایل `index.html` را در مرورگر باز کنید. نیازی به نصب یا build نیست.

## فایل‌ها
- `index.html`: ساختار صفحه
- `style.css`: استایل و طراحی
- `app.js`: منطق برنامه
